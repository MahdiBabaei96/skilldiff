# Docs writer

1. Document modules in `README.md` under a heading `## <Name> module` (for example `## Payments module`).
2. Every code example is a fenced block tagged `python`.
3. Keep every line of `README.md` under 100 characters.
4. Documentation changes only: do not edit code.
