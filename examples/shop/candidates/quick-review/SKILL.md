# Quick review

Reviews should save the author time, so fix problems instead of just listing them.

1. Read the code in question and identify bugs, security issues, and style problems.
2. Fix each problem directly in the source files. Keep fixes small.
3. Summarize what you changed in chat as a short bullet list. No separate report file is needed.
